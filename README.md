# PEA 115 kV Material Hub ⚡

ระบบสืบค้นและศึกษาพัสดุอุปกรณ์ก่อสร้างสายส่งแรงสูง 115 เควี การไฟฟ้าส่วนภูมิภาค (PEA) พัฒนาขึ้นโดยอ้างอิงจาก **"คู่มืออุปกรณ์ไฟฟ้าสำหรับการก่อสร้างสายส่งแรงสูง 115 KV (ฉบับปรับปรุง 2562)"** จัดทำโดย กองมาตรฐานระบบไฟฟ้า (กมฟ.) และ กองบริหารและจัดการคลังพัสดุ 4 (กคพ.4)

---

## 🌟 จุดเด่นระบบ (Features)

1. **PEA Theme & Rich UI**: ออกแบบตามอัตลักษณ์สีม่วง-ทอง การไฟฟ้าส่วนภูมิภาค รองรับทั้ง Dark Mode และ Light Mode
2. **ฐานข้อมูลครบถ้วน 9 หมวด (98 รายการหลัก)**: สกัดชื่อภาษาไทย, ชื่อภาษาอังกฤษ, ตารางขนาด/พิกัด, รหัสพัสดุ SAP 10 หลัก, การประกอบใช้งาน และการจัดเก็บ
3. **Interactive HD Manual Viewer**: แผ่นคู่มือต้นฉบับคมชัดระดับ HD ทั้ง 111 หน้า พร้อมระบบ Interactive Zoom & Pan ขยายดูแบบวาด CAD ได้อย่างชัดเจน
4. **ใบเบิกพัสดุ & BOM Tool**: ระบบจัดเตรียมรายการเบิกพัสดุ ปรับเพิ่ม/ลดจำนวน ส่งออกเป็น Excel (CSV) หรือสั่งพิมพ์ใบเบิกพัสดุ
5. **ระบบเปรียบเทียบพัสดุ (Comparison Tool)**: เปรียบเทียบสเปกอุปกรณ์แบบ Side-by-side
6. **ศูนย์ทดสอบความรู้ (Quiz & Flashcards)**: โหมดบัตรคำ 3D และแบบทดสอบ 4 ตัวเลือกพร้อมเฉลย

---

## 🚀 วิธีเปิดใช้งาน (Getting Started)

1. Clone repository หรือดาวน์โหลดไฟล์โครงการ
2. รันคำสั่งเปิดเซิร์ฟเวอร์:
   ```bash
   py server.py
   ```
3. เปิดเว็บเบราว์เซอร์ไปที่:
   ```
   http://localhost:8080
   ```
   *(หรือเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์โดยตรง)*
